# NexoTune

Aplicativo portátil em português para revisar ajustes, diagnosticar problemas e gerenciar aplicativos no Windows.

Projeto de [Pedroz4002](https://github.com/Pedroz4002).

[Baixar NexoTune.exe](https://github.com/Pedroz4002/NexoTune/releases/latest/download/NexoTune.exe) · [Notas da versão e SHA-256](https://github.com/Pedroz4002/NexoTune/releases/latest)

## Como usar

1. Baixe **NexoTune.exe** em **Assets** na página da versão.
2. Abra com dois cliques e confirme o pedido de administrador do Windows para acessar os ajustes do sistema.
3. Use **Detalhes** em cada ajuste para ver seu efeito. Para recuperar as preferências anteriores, abra **Backups**.

O app funciona no Windows 10 e 11 x64 com .NET Framework 4.7.2 ou posterior. Algumas opções dependem da versão do Windows, da edição ou do hardware. O executável é portátil e reúne a interface, o catálogo e a ajuda.

## O que você encontra no app

- **Ajustes** com interruptores, perfis e backup automático dos valores anteriores.
- **GPU e jogos** com detecção da placa, medição de uso e memória e preferências gráficas do Windows.
- **Rede** com medições de ping e variação, perda de respostas e traçado de rota.
- **Aplicativos** com desinstalação individual e quarentena para programas elegíveis.
- **Diagnóstico** com identificação do processador, medições de CPU, RAM e disco e atalhos para ferramentas do Windows.
